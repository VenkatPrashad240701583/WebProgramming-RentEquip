THE CAMPUS CHALLENGE
Problem Statement
02 / 10
Challenges College Students Face
Forgotten Essential Items:

Students often forget vital supplies such as pens, scientific calculators, lab coats, and drawing tools right before exams or lab practicals.

High Cost for Single-Semester Use:

Buying specialized equipment for one-time or temporary use is expensive and financially burdensome.

Struggle with Temporary Needs:

Students struggle to find tools needed only for short-term project presentations or practical sessions.

No Centralized Campus Marketplace:

There is no convenient, organized college marketplace for students to borrow or rent items from peers.

PROJECT OVERVIEW
Proposed Solution — RentEquip
03 / 10
A Smart Campus Sharing Network
Direct Peer Connection:

RentEquip connects students who need items with students, seniors, and campus clubs who own them.

Browse, Search & Rent:

Users can browse, search, and rent essential academic items for flexible daily durations.

Owner Listing Tools:

Owners can easily list idle items, set daily prices and security deposits, and manage incoming requests.

Single Unified Platform:

A single web application simplifies the entire rental, pickup, and deposit settlement process.

WHAT STUDENTS CAN DO
Key Features
04 / 10
Core Application Capabilities
Search & Filter:

Search and filter equipment by category, student price budget, availability, and campus locations.

Diverse Academic Inventory:

Browse stationery, engineering drawing tools, lab essentials, electronics, art supplies, and textbooks.

Submit & Track Requests:

Submit rental requests, check live availability, and track request status seamlessly.

Deposits, Returns & Reviews:

Manage equipment listings, approve or reject requests, track security deposits, and submit peer reviews.

System Workflow Flowchart

PLATFORM STAKEHOLDERS
User Roles & Ecosystem
06 / 10
Three Distinct Campus Roles
1. Customer (Student Borrower):

Searches for academic items, requests rentals, tracks active bookings, confirms pickups, and submits reviews.

2. Equipment Owner (Student Lender):

Lists items, sets prices and deposits, manages borrow requests (approve/reject), and conducts return inspections.

3. Admin (Student Affairs Council / SAC):

Oversees user accounts, listings catalog, rental transactions, monitors overdue alerts, and maintains data tools.

WEB STACK OVERVIEW
Technology Used
07 / 10
Simple, Native Web Architecture
HTML:

Builds the web pages, accessible forms, modal structures, and semantic layouts.

CSS:

Provides the campus-themed design, responsive Flexbox/Grid layouts, and smooth animations.

JavaScript:

Handles user interactions, rental calculations, date conflict checking, and application logic.

Browser localStorage:

Saves all demonstration data, bookings, users, and reviews directly in the browser.

HOSTING & DELIVERY
Deployment and Accessibility
08 / 10

Hosted on GitHub Pages:

The website is deployed online using GitHub Pages, making it publicly accessible anytime.

No Software Installation:

Runs immediately in any standard desktop or mobile web browser without extra tools.

Cross-Device Responsive:

Adaptive design works seamlessly across smartphones, tablets, and laptops.

IMPACT & ROADMAP
Benefits and Future Scope
09 / 10
Immediate Value & Future Vision
Key Benefits:

Makes essential academic items easier to find, encourages affordable reuse, helps students earn from idle gear, and builds campus community sharing.

Future Scope:

SUMMARY
Conclusion
10 / 10
Project Takeaways
Practical Campus Marketplace:

RentEquip provides a convenient campus-focused rental marketplace connecting student owners with students needing temporary access to essential items.

Core Web Engineering:

The project demonstrates how HTML, CSS, and JavaScript can be combined to build an interactive, responsive web application deployed live online.
